# ADR-0008: k-Core 确定性剪枝替代随机聚类

## 状态

采纳（2026-06-24）

## 问题

传统聚类算法（如 Louvain）具有随机性，同一图谱多次运行可能产生不同结果，导致 Helix 的记忆"飘忽不定"。

## 决策

在 Deep Dream 时对 L2 图谱执行 $O(V+E)$ 的 k-Core 分层等级划分。k-Core 是确定性算法，同一图谱永远产生相同的分解结果。

## 权衡

| 优势 | 代价 |
|:---|:---|
| 结果完全确定，可复现 | k-Core 可能过度剪枝，丢失有价值的边缘知识 |
| 计算极快，线性复杂度 | 需要选择合适的 k 值 |
| 数学上优雅 | 对稀疏图效果可能不佳 |

## 回滚阈值

若 k-Core 剪枝导致检索召回率下降 &gt; 10%，则引入辅助的语义相似度阈值作为补充。

## 相关原则

- 极致节能（公理七）——k-Core 比迭代聚类更节能
- 物理事实优先（DNA 第一性原则）
