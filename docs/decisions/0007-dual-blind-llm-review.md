# ADR-0007: 双盲 LLM 审查防注入

## 状态

采纳（2026-06-24）

## 问题

恶意节点可能通过构造特殊内容进行提示词注入攻击，在联邦 Review 时劫持 Reviewer LLM 的行为。

## 决策

- 零上下文污染：待审节点内容封装在独立 System Prompt 分区
- 纯判别输出格式：强制 JSON 输出，非 JSON 或含指令性文本直接判定失败
- 双盲验证：同一节点使用两个独立 LLM 实例审查，不一致则标记存疑
- 沙箱节点禁止输出：合并前强制清空 `suggested_actions`
- 高风险节点标记：系统级操作知识额外标记 `high_risk: true`

## 权衡

| 优势 | 代价 |
|:---|:---|
| 有效防御提示词注入 | 双盲验证使 Review 成本翻倍 |
| 结构化输出可审计 | 可能增加假阴性（合法节点被误杀） |

## 回滚阈值

若双盲验证的假阴性率 &gt; 15%，则改为单盲 + 更严格的输出格式校验。

## 相关原则

- 物理事实优先（DNA 第一性原则）
- 基因锁是社会协议（公理六）
