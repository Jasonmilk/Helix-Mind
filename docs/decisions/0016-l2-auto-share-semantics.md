# ADR-0016: L2 自动共享语义（宪法级锁定）

## 状态

采纳（2026-08-27）

## 问题

VISION.md 初版方案将 L2 共享表述为"主动共享、不属于整个物种"，与 `ECOSYSTEM.md §7`、`docs/spec/federation.md`、`docs/spec/data-contract.md` 的宪法级"公开 DAG 自动共享"直接冲突。存在被再次误读为"主动共享"的风险。

## 决策

L2 一经提炼并完成隐私洗脱，**自动汇入 Rhizax 种群知识树**，无需个体逐节点门禁决策。"自动"有两层含义：

1. 不需要个体逐节点做"是否发布"的决策（极致节能）。
2. 自动不等于无前提——前提是：L2 已通过 L3→L2 提炼，并完成隐私洗脱，剥离个体信息。

**气态不入种群知识树。**

**宪法不变**：`ECOSYSTEM.md §7`、`docs/spec/federation.md`、`docs/spec/data-contract.md` 的"公开 DAG 自动共享"保留原措辞。ADR-0016 作为其**执行澄清**，而非修正。

## 权衡

| 优势 | 代价 |
|:---|:---|
| 消除 L2 归属歧义（物种知识 vs 个体财产） | 共享是强制性的——私藏不被允许 |
| 隐私由洗脱前置保障，个体免于逐节点决策负担 | 洗脱管道必须可靠，否则隐私泄露 |
| 与"知识属于物种""极致节能"公理完全一致 | — |

## 回滚阈值

不适用——此为宪法级澄清，非工程可逆决策。若未来物种宪法被重新商权（用户明确发起），以新 ADR Supersede 本卡。

## 相关原则

- 知识属于物种，记忆属于个体
- 极致节能（不为每个节点做发布决策）
- 相态管控共享准入（ADR-0011：非气态 + 低主体依赖）
