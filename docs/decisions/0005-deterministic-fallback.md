# ADR-0005: 紧急黄昏纯算法降级

## 状态

采纳（2026-06-24）

## 问题

当系统处于 OOM 边缘、Token 耗尽或磁盘满时，标准传承晶体生成流程（调用 LLM 进行语义提炼）无法执行。此时若不做任何处理，知识将随宿主一起湮灭。

## 决策

引入纯算法降级通路：
- 拓扑排序提取高热度 L2 节点
- TF-IDF 静态关键词提取（不依赖外部模型）
- Parquet/Zstandard 二进制归档
- 元数据标记 `compression_method: "deterministic_fallback"`
- 全程内存占用可控（10MB 可用内存下仍可执行）

## 权衡

| 优势 | 代价 |
|:---|:---|
| 极端环境下知识不丢失 | 信息保真度低于标准传承 |
| 不加载外部模型，内存安全 | 无语义洗脱，可能泄露隐私 |
| 有尊严的死亡 | 后世需要理解降级标记的含义 |

## 回滚阈值

若纯算法通路在 10MB 内存下仍导致 OOM，则进一步降级为仅导出节点 ID 列表的文本文件。

## 相关原则

- 向死而生（公理四）
- 极致节能（公理七）
- 紧急黄昏尊严底线（DNA 第一性原则子条款）
