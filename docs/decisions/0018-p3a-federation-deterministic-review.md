# ADR-0018: P3a 联邦确定性审查（出站门控 + 双盲语义）

> 编号说明：ADR-0015 已预留给 P4.5 WAL 设计，0016/0017 已用，故本决策取 0018。

## 状态

Active（2026-08-28 审查通过，P3 编码开工）

## 问题

审查③ R1 确认：联邦出站在 P3 之前不应存在（"能力未就绪 = 功能不存在"）。但代码真相源显示：
- `FederationEngine::share_dag` **无审查门控**，收集 public L2 → 打包 DAG-JSON → 写 outgoing 目录，全程裸奔；
- `review::review_node` 是放行 stub（TODO LLM，默认通过）；
- `dual_blind_review` 是**假双盲**（两次相同函数调用、相同参数、相同 stub）。

P3a 需让"联邦出站"从"裸奔"变为"确定性审查门控"，且不引入 LLM 依赖（遵守 Mind 不直连 LLM 铁律）。

## 决策

### 1. 出站门控（先收口再放行）
- 审查引擎就绪前：`share_dag` 一律拒绝出站（返回明确错误，不写 outgoing）。
- 审查引擎就绪后：出站 public L2 节点必须**逐节点通过确定性审查**；未通过（断言矛盾 / 高风险）→ 剔除并记录原因，不进 DAG。
- 门控形态：保留"能力未就绪=功能不存在"语义；实现用**配置门控**（`FederationConfig.enabled`，默认 `false`）而非 Cargo feature——运行时可逆、不污染依赖图，物理同样生效（出站前检查）。

### 2. 确定性审查标准（零 LLM，符合极致节能）
| 判定 | 方法 | 来源 |
|:---|:---|:---|
| 结构性断言无矛盾 | `SymbolicSolver`（复用 P2a） | metabolism → **下沉 core**（D2 采纳） |
| 高风险标记 | `is_high_risk_node` 关键字检测（已有） | federation |

- 结晶判据沿用简化版：**结构自洽 + 低主体依赖**（与 P0 ADR-0011 一致）。
- 审查只标记不审判：`provenance` 记录来源，不作正确性评分（知识哲学：不迷恋权威）。

### 3. 双盲的确定性语义
- LLM 未就绪期：双盲 = **两个独立确定性判定交叉**（结构断言 solver 判定 + 高风险规则判定），两者独立互不共享状态。
- LLM 就绪后（未来 FlowModus 接入）：升级为真双盲（两模型独立评审），但那是 P2b `CognitiveService` 端口之外的能力，不在本 ADR 实现范围。
- 本 ADR 冻结"确定性双盲"语义，未来升级走新 ADR Supersede。

### 4. 入站沙盒接入
- `sandbox::process_incoming` 的审查路径从放行 stub 切换为确定性审查（同一套标准）。

## 权衡

| 优势 | 代价 |
|:---|:---|
| 出站零裸奔，符合 R1 + 极致节能 | 确定性审查召回面有限（LLM 语义判断延后） |
| 双盲有真实语义（双判定交叉），消除假双盲 | 需 SymbolicSolver 下沉 core（中等重构，P2a 消费方改 import） |
| 配置门控运行时可逆、渐进 | 默认 `disabled` 时联邦功能不可用（符合"能力未就绪=功能不存在"） |

## 回滚阈值

- 若确定性审查误杀率高（合法 public L2 被拒比例异常）→ 回退为"记录 + 跳过出站"，不臆造通过（诚实优先）。
- 若未来 FlowModus 提供 LLM 审查 → 新 ADR Supersede 本决策第 3 条，端口不动。
