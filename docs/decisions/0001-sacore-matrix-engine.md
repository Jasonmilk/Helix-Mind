# ADR-0001: SA-Core 稀疏矩阵引擎替代 LLM 寻路

## 状态

采纳（2026-06-24）

## 问题

运行时 LLM 寻路成本过高。每次检索调用 LLM 进行图遍历决策，Token 消耗巨大，延迟在百毫秒级，无法满足高频交互需求。

## 决策

引入 SA-Core 引擎，通过纯数学稀疏矩阵乘法在内存拓扑层中完成寻路，运行时 0 Token 消耗，微秒级响应。

## 权衡

| 优势 | 代价 |
|:---|:---|
| 0 Token 消耗 | 丧失 LLM 的语义灵活性 |
| 微秒级响应 | 需要维护内存拓扑层，增加内存占用 |
| 数学上可证明收敛 | 矩阵构建和维护有工程复杂度 |
| 负权重自动抑制旧认知 | 需要精心设计权重映射规则 |

## 回滚阈值

若 SA-Core 在以下场景表现劣于 LLM 寻路，则回滚：
- 跨领域联想任务准确率下降 > 15%
- 内存拓扑层维护导致 OOM 频率增加
- 辩证边抑制过于激进，导致合法旧知识被误杀

## 相关原则

- 极致节能（公理七）
- 认识论螺旋（公理七子条款）
