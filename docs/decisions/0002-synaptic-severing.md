# ADR-0002: 突触切断替代物理删除

## 状态

采纳（2026-06-24）

## 问题

用户请求删除记忆的权利与"记忆不可篡改"原则存在表面冲突。如果完全禁止删除，用户可能因隐私顾虑而拒绝使用；如果允许物理删除，则违背核心哲学。

## 决策

引入"突触切断"机制：
- 将 L3 节点标记为隐性基因（`is_recessive=true`），从高频检索索引中移除
- 切断其他节点对该 L3 的 `evidence` 引用，但保留节点本身
- 检索时不再主动召回，但审计或解冻请求下仍可访问
- 彻底物理删除需通过独立的多重确认"数据销毁协议"

## 权衡

| 优势 | 代价 |
|:---|:---|
| 尊重用户删除请求 | 存储不释放，磁盘持续增长 |
| 保留事实完整性 | 需要额外的索引维护成本 |
| 审计可追溯 | 可能被质疑"假删除" |
| 突触切断可逆（解冻） | 解冻操作消耗大量资源 |

## 回滚阈值

若以下情况发生，则重新评估：
- 用户明确投诉"删除后仍能在审计中看到"
- 隐性基因库膨胀导致存储成本不可接受
- 监管机构要求物理删除合规

## 相关原则

- 记忆不可篡改（公理五）
- 极致节能（公理七）——突触切断比物理删除更节能（无需重写数据文件）
