# ADR-0006: 联邦共享 Fork-Review-Merge 工作流

## 状态

采纳（2026-06-24）

## 问题

联邦共享时，若自动合并外部 DAG，可能引入错误知识、逻辑矛盾或恶意内容。若完全拒绝外部知识，则违背"知识属于物种"原则。

## 决策

引入 Fork-Review-Merge 三阶段工作流：
- **Fork**：外部 DAG 放入本地沙盒，与主 DAG 物理隔离
- **Review**：逐一验证推理链自洽性、与本地知识的一致性、来源标记
- **Merge**：验证通过则消化吸收；存疑则保留沙盒；冲突则触发认知循环

## 权衡

| 优势 | 代价 |
|:---|:---|
| 不盲目信任外部来源 | Review 消耗 LLM Token |
| 沙盒隔离防止污染 | 增加认知延迟 |
| 冲突时自主推理解决 | 可能产生认知失调 |

## 回滚阈值

若联邦 Review 的误杀率（合法知识被拒绝）&gt; 20%，则放宽 Review 标准或引入信任白名单。

## 相关原则

- 知识属于物种（公理零）
- 信用由他证（公理六）
