# ADR-0021: 认知工艺（Cognitive Craft）——"如何思考"系统

> **编号说明**：ADR-0015 预留给 P4.5 WAL，0016-0020 已用，故本决策取 0021。
> **决策日期**：2026-08-28
> **审查来源**：认知工艺升级计划 v1.1（吸收 Gemini 审查补丁 7 项）+ 豆包严肃审查（B1/B2/B3 三项修正）
> **状态**：Active（2026-08-28 用户批准，P7 认知工艺 Phase 1 落位）

## 问题

Helix-Mind 已有完整认知循环，但缺乏对"如何思考"的显式控制：简单问题过度思考、复杂问题思考不足；熟练模式路径依赖导致思维僵化；无显式工序编排；无会话隔离导致思考维度互相污染。

认知工艺是 Helix 的"如何思考"系统：**根据问题复杂度与类型，自主选择思考方式，必要时拆解为多道独立工序，最后整合为高质量答案；通过睡眠复盘与随机变异维持思维多样性。**

## 决策

### 1. 执行边界（B1 修正，硬线）：Mind=编排建议，CognitiveService=执行

- **Mind 内的认知工艺编排 = 纯逻辑（0 Token）**：System 0 门控、工序选择、MSC 组装、收敛判断。
- **"独立会话执行"必须通过 ADR-0017 `CognitiveService` trait 注入**（生产默认 `DeterministicAdapter`，`debug_direct` 才允许 `RemoteAdapter`）。
- **禁止** Mind 直接持有/发起 LLM HTTP 调用（延续 Z2 锁死：Mind 不直连 LLM）。任何越界实现视为架构违规。

### 2. System 0 启发式门控（B2 修正）：规则 + FTS5 相关度，非 embedding

- 门控方式（全部 0 Token，复用 M-01 已有设施）：
  1. **规则匹配**：问题长度、关键词、历史相似问题匹配。
  2. **FTS5 bm25 相关度阈值**：与已知简单问题的相似度用 bm25 命中分数表达（替代"嵌入距离"——当前代码零 embedding 基础设施，引入即违反极致节能）。
  3. **用户意图标签**：用户显式指定"帮我深入分析"则跳过门控。
- **递归禁用**：门控阶段严禁调用认知工艺本身。
- Phase 3 若引入向量门控，走外部向量库，不进 Mind 内核。

### 3. 与 ADR-0010 认知预算的边界（B3 修正）

| 机制 | 层级 | 决定什么 |
|:---|:---|:---|
| **预算路由**（ADR-0010） | 外部前置（Callosum） | 检索**扫描范围**（相态） |
| **System 0 门控**（本 ADR） | Mind 内 | 思考**深度**（是否触发认知工艺） |

两者正交，不冲突。未来任何实现不得混用。

### 4. 工序编排 + 独立会话隔离

- **5 种工序**（正交于 3 种运行模式）：结构性 / 批判性 / 创造性 / 情境意图解析 / 元批判。
- **独立会话**：每道工序启动独立会话，注入 **MSC**（最小充分上下文）：
  - `[原始输入原文（不可裁剪——事实锚点）] + [该工序专有 Prompt] + [全局约束 Schema]`
  - 严禁子工序之间横向引用中间草稿。
  - 共享主 `trace_id`（W3C TraceContext，全息留痕-交互追溯）。

### 5. 黑格尔辩证收敛协议（R1 确定性合题）

- **正题**：提取结构/创造工序的核心主张。
- **反题**：提取批判工序的证伪边界与风险。
- **合题（确定性规则，非 LLM 自由发挥）**：条件约束下的结构化重构——**保留正题的陈述性内容 + 注入反题的防御性约束 → 输出条件化命题**。
- 合题操作必须可审计、可复现。

### 6. 抗僵化机制（R3 确定性信号）

- **Bounded ε-Greedy + EMA 自适应突变率**：突变率下限 3%、上限 20%；成功率用 EMA 平滑。
- **成功率信号 = 确定性信号**（任务完成标志、重试率），**禁用 LLM 自我评分**（信用由他证）。
- **多样性路径池**：L1 自画像维护 2-3 条"曾经有效但当前非最优"备份路径。
- **睡眠复盘**：在 Deep Dream 代谢窗口内执行"非熟练模式检视"（强制锚定/想象力模式，防假复盘），**不阻塞主认知循环**（R4）。

### 7. Token 熔断 + 超时（P6 工程防护）

| 防护 | 默认值 |
|:---|:---|
| 最大子工序数 | 5 |
| 单工序 Token 上限 | 由全局预算分配 |
| 总 Token 预算 | EnergyContext（ADR-0010 前置路由） |
| 子工序超时 | 30s（超时自动终止，返回部分结果） |

## 权衡

| 优势 | 代价 |
|:---|:---|
| 简单/复杂问题差异化处理，极致节能 | 编排器增加系统复杂度（Phase 2 最小原型控制） |
| 会话隔离防思考污染，输出质量提升 | 独立会话增加 Token 消耗（System 0 门控只对高价值触发） |
| 抗僵化 + 收敛协议闭环 | 收敛合题需确定性规则（已定义，防自由发挥） |

## 回滚阈值

- Phase 2 最小原型若编排逻辑不可验证（无法用 DeterministicAdapter 闭环）→ 回退为"单会话直接收敛"（跳过独立会话隔离），新 ADR Supersede 本决策。
- 若 bm25 相关度门控误判率过高 → 回退为纯规则匹配（更保守），不引入向量依赖。
