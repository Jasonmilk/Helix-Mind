# ADR-0003: 数据库独占所有权，gRPC 唯一通道

## 状态

采纳（2026-06-24）

## 问题

多进程同时读写 SQLite 导致文件锁竞争、数据损坏、真理源不单一。Anaphase 的 `helix kb` 命令直接操作数据库文件，绕过 Mind 的业务逻辑。

## 决策

- 磁盘上的所有持久化数据物理上仅由 Helix-Mind 进程独占持有并锁定
- 任何其他组件（包括 Anaphase）不得直接读写这些文件
- 所有知识访问必须通过 Helix-Mind 暴露的 gRPC 接口进行
- Anaphase 的 `helix kb` 命令改为通过 gRPC 向 Mind 发送请求

## 权衡

| 优势 | 代价 |
|:---|:---|
| 消除文件锁冲突 | 增加一次 RPC 延迟（毫秒级） |
| 真理源单一性 | 需要维护 gRPC 服务的高可用 |
| 业务逻辑统一入口 | 调试时需要穿透 gRPC 层 |
| 安全边界清晰 | 跨语言绑定增加复杂度 |

## 回滚阈值

若 gRPC 通信成为性能瓶颈（P99 延迟 > 10ms），则考虑共享内存或 mmap 方案，但仍保持 Mind 的独占写入权。

## 相关原则

- 物理事实优先（DNA 第一性原则）
- 最小权限（架构法则）
