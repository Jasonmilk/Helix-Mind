# ADR-0009: 跨学科语义剪枝

## 状态

采纳（2026-06-24）

## 问题

检索时无关学科的知识节点消耗 Token 预算，降低回答质量。但完全隔离学科会阻碍跨界创新。

## 决策

- L2 节点携带可选 `domain` 属性
- 加载矩阵 $W$ 时瞬间剪掉无关学科边，保留桥接节点（连接不同学科的共享概念）
- 预算充裕（向阳度高）时允许能量通过桥接节点流向相邻学科
- 预算紧张时严格限定在目标学科内

## 权衡

| 优势 | 代价 |
|:---|:---|
| 避免 Token 浪费 | 桥接节点的识别需要维护 |
| 安全的跨界联想 | 可能错过隐含的跨学科关联 |
| 用户可指定领域 | 增加配置复杂度 |

## 回滚阈值

若跨学科剪枝导致创新性问题（如"物理学与哲学的交叉"）回答质量下降，则放宽桥接节点的能量传递阈值。

## 相关原则

- 极致节能（公理七）
- 检索策略属于 Mind（公理二）
