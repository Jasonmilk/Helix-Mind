# 知识代谢闭环

## 六阶段循环

Helix-Mind 的知识不是静态存储，而是一个持续代谢的生命过程。从摄入到复用，六个阶段循环往复，从未停歇。

```
摄入 (Tentacle/Anaphase/想象力)
    │
    ▼
消化 (Micro-Sleep: 去重合并 + 认知失调检测)
    │
    ▼
吸收 (Deep Dream: 提炼 L2 经验原则 + 隐私洗脱)
    │
    ▼
存储 (L2 写入 DAG，高频节点 → Callosum 前缀池)
    │
    ├── 高频复用 → Callosum 毫秒级响应，零 Token 成本
    │
    └── 低热衰减 → Heat 自然衰减
              │
              ▼
遗忘 (is_recessive=true，归档隐性基因库)
              │
              ├── 复活窗口内被重新激活 → 恢复为 L2，Heat 重置
              │
              └── 超过复活窗口 → 索引可删，记忆深冷归档
```

### 各阶段机制

| 阶段 | 名称 | 触发 | 机制 | 产物 |
|:---|:---|:---|:---|:---|
| **摄入** | Ingestion | Tentacle 抓取 / Anaphase 推理 / 想象力模式 | 外部数据进入 Mind | 原始 L3 节点 |
| **消化** | Digestion | Micro-Sleep（事件驱动，非定时） | TF-IDF / Jaccard 去重，合并相似度超过阈值的 L3 碎片；检测认知失调；检查共享知识树引用更新 | 去重后的 L3 节点 + 失调事件 |
| **吸收** | Absorption | Deep Dream（系统空闲时） | LLM 提炼 L3 → L2 经验原则；隐私洗脱 | L2 节点 |
| **存储** | Storage | 吸收完成后 | L2 写入 DAG；高频节点推送 Callosum 静态前缀池 | 持久化 L2 + 缓存指针 |
| **遗忘** | Forgetting | Heat 自然衰减 + 隐性基因归档 + 突触切断 | 低热度节点标记 `is_recessive=true`，从高频索引移除；用户请求删除时执行突触切断 | 隐性基因 |
| **复用** | Recycling | 检索时 | Callosum 缓存命中 → 零 Token；未命中 → SA-Core 内存拓扑层检索 | 检索结果 |

## 事件驱动的代谢触发

代谢不再仅依赖固定周期，而是由事件驱动。这完全符合铁律 13（绝无心跳，事件驱动）。

| 代谢类型 | 触发条件 | 执行逻辑 |
|:---|:---|:---|
| **Micro-Sleep** | 每 N 次 L3 写入后触发（默认 N=50），或在系统空闲时触发 | 去重合并、认知失调检测、共享知识树引用检查 |
| **Deep Dream** | 系统空闲 + 有待办积累（待结晶 L3 碎片超过阈值） | L3→L2 提炼、隐私洗脱、结晶写入、k-Core 确定性剪枝 |
| **困惑畅想** | 仅当 `impasse_depth >= Deep` 且系统空闲时触发 | 天马行空探索，沙箱隔离 |
| **深眠** | 仅当连续空闲 > 阈值（默认 2 小时） | 深冷归档、索引压缩、传承晶体草稿更新 |

**空闲检测机制**：基于 `tokio::select!` 的空闲等待，非定时器。一旦有新请求到达，`select!` 立即跳出空闲状态去处理请求。没有任何 CPU 周期浪费在轮询上。

## 代谢事务安全公约

所有代谢任务必须遵循以下安全公约：

1. **微步长设计**：每个代谢任务被拆分为独立的微步长。步长之间是安全的打断点。
2. **ACID 事务包裹**：每个微步长必须封装在单一的数据库事务中。提交成功则数据完整落盘，任何失败则自动回滚。
3. **优雅拒绝，非暴力终止**：当高优先级请求到达时，系统等待当前微步长事务完成（最大耗时可控，默认 < 100ms），然后拒绝启动下一个微步长。
4. **孤儿节点防护**：所有写操作遵循"先写子节点，后写父节点"的拓扑顺序。
5. **空闲检测非心跳**：`tokio::select!` 中的空闲等待是可被打断的休眠，不是定时器。

## 知识代谢等级制

知识并非生而平等。不同类型的知识享有不同的生命周期权利。

| 知识类型 | 存储层 | 遗忘机制 | 复用路径 |
|:---|:---|:---|:---|
| **L0 基因锁** | 独立文件 `gene_lock.md` | **永不遗忘** | 每次认知循环前强制注入 |
| **L1 自画像** | DAG 节点 + 记事本 DAG | 每世重置 | 每次检索时优先加载 |
| **L2 经验原则** | DAG 节点 + Callosum 静态前缀池 | Heat 衰减 + 隐性基因归档 | Beam Search 高权路径；可通过联邦共享 |
| **L3 情景记忆** | 只增不改的日志流 | Micro-Sleep 去重合并；Deep Dream 提炼后进入隐性基因库；请求删除时突触切断 | 极少数被检索唤醒 |
| **虚构记忆** | 沙箱分支，`is_hypothetical=true` | 验证失败则标记存疑；验证通过则剥离标签，升级为 L2 | Anaphase 现实验证 |

## 认知失调触发器

当新摄入的 L3 记忆与 L2 知识图谱中某节点存在逻辑矛盾时，Mind 启动结构化的自我质疑流程——**批判性微睡眠**。

### 触发条件

- 新 L3 节点与已有 L2 节点向量相似度超过配置阈值
- 但语义关系为 NEGATION（矛盾）

### 批判性微睡眠流程

1. **检测矛盾**：Micro-Sleep 发现新 L3 与旧 L2 存在逻辑冲突
2. **生成假设节点**：在沙盒中创建 `H`（`is_hypothetical=true`），提出质疑
3. **调用 LLM 推演**：使用独立的批判性推理 Prompt 模板
4. **推演结果**：
   - **推演通过**：生成新认知节点 `A'`，建立辩证边 `A' --[CORRECTS]--> A`
   - **推演不通过**：保留矛盾标记，等待更多证据
5. **记录过程**：整个批判过程写入 L3

## 记忆时效分级

| 记忆层级 | 时间范围 | 存储位置 | 遗忘策略 | 检索优先级 |
|:---|:---|:---|:---|:---|
| **临时记忆** | 当前认知循环内 | 内存（不持久化） | 循环结束自动清除 | 最高 |
| **短期记忆** | 当前会话 | L3 热区 | 会话结束后转为中期 | 高 |
| **中期记忆** | 数天到数月 | L3 主存储 | Heat 衰减 + Micro-Sleep 去重 | 中 |
| **长期记忆** | 数月到一世 | L3 归档 / 隐性基因库 | Deep Dream 提炼为 L2，原 L3 归档 | 低（按需激活） |

### 综合评分

记忆的存留不纯靠热度。在 Deep Dream 中，综合评分由四维决定：

```
retention_score = f(heat, recency, initial_impact, reusability)
```
