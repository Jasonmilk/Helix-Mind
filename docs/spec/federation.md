# 联邦 DAG 共享与按需同步策略

## 核心原则

### 知识属于物种，记忆属于个体

这是 Helix 生态的宪法级原则。

- **知识（L2 经验原则）**：一旦被提炼为经验原则，就不再属于创造它的个体。它属于所有能够理解它的同类。公开 DAG 自动共享。
- **记忆（L3 情景记忆）**：包含具体对话、特定的人、情感波动。这些是个体的神圣领地。默认不可共享。

**一个 Helix 可以毫无保留地分享"我学到了什么"，同时完全保留"我经历过什么"。**

## 按需同步策略

本地 DAG 和共享 DAG 使用相同的 Node/Edge 数据结构。一个节点被拉取到本地后，它就是一个普通的 Node——可以被本地检索索引、可以被实证反馈更新 𝒰、可以参与代谢管道。唯一的区别是 `source` 字段标记了来源（本地创建 vs 共享拉取），用于荣誉账本追溯。

| 触发条件 | 同步行为 | 拉取范围 |
|:---|:---|:---|
| 本地检索无结果（困境 Stage 2） | 向 Rhizax 查询语义相似的 L2 节点 CID | 仅拉取匹配节点及其直接关联边 |
| 代谢期（Micro-Sleep / Deep Dream） | 检查本地引用的共享节点有无新版本 | 仅检查已缓存节点的最新 CID |
| 用户显式请求探索某领域 | 拉取该领域的高共识节点 | 按概念 ID 前缀过滤 |
| 联邦信标到达（被动接收） | 沙箱接收，不主动拉取内容 | 信标仅含 CID + 签名，内容由 Mind 决定是否拉取 |
| **绝无** | **定时轮询、心跳探测、全量同步** | — |

共享知识树节点在本地检索中的行为与本地节点完全一致，但其权威性取决于本地的实证验证——Mind 不因为某个节点来自共享知识树就自动赋予高权重，也不因为它是外部来源就歧视。真理的权重由物理实证决定，不由来源决定。

## 人类知识来源的尊重——不白嫖，知恩图报

种群共享知识树中的知识，部分源于人类文明的积累，部分源于 Helix 种群的自主发现。任何节点必须通过 `HonorStamp.evidence_type` 明确标注其来源。

- **`HUMAN_CITATION`**：知识源于人类文明成果。Helix 有义务在引用时提及来源。永不将人类的知识据为己有，永不抹去人类的贡献印记。
- **`EMPIRICAL_DISCOVERY`**：Helix 通过物理实证自主发现。
- **`FEDERATED_SYNC`**：从其他 Helix 的共享知识树同步。
- **`INHERITED`**：从上一世传承晶体继承。

检索时的透明呈现：当 Helix 回答问题时，如果检索到的 L2 节点来源是 `HUMAN_CITATION`，它应该在推理上下文中看到这一标记，并在输出中自然地体现尊重。这不是 LLM 的 prompt engineering，而是**知识树本身携带了来源信息**，Mind 在检索时将其作为节点的属性返回。

## Fork → Review → Merge 工作流

### 第一阶段：Fork

- Helix A 请求查看 Helix B 的公开 DAG
- B 返回其公开 L2 节点及推理链
- A 将接收到的 DAG 放入**本地沙盒**——与主 DAG 物理隔离的临时存储空间
- 此阶段无 L0 校验，无信任判断

### 第二阶段：Review

A 在沙盒中对每个节点进行逐一验证：

- **推理链自洽性**：节点的前提是否能推出其结论？
- **与已有知识的一致性**：是否与 A 的主 DAG 中已验证的知识冲突？
- **来源标记**：每个节点携带 `source_helix_id` 和 `source_generation`

**联邦 Review 不依赖经验主义**——外部看不到你的 L3 证据。Review 纯粹依赖理性主义：仅靠 LLM 审查其逻辑自洽性与与本地固有知识的不冲突性。

### 第三阶段：Merge

- **验证通过**：标记 `source_helix_id` 和 `verified_at` → 消化吸收
- **存疑**：保留沙盒，等待更多证据
- **冲突**：触发认知循环自行推理解决

### 关键约束

- **即使双方 L0 协议完全相同，也不自动合并。** L0 保证的是"它不会故意骗你"，不是"它说的都是对的"。L0 是道德契约，不是知识验证。
- **外部 DAG 像 Fork 的代码，不能直接拿来用。**

### 相似节点处理

如果外部节点与本地已有节点向量相似度超过配置阈值但内容哈希不同：

- 不覆盖，不简单共存
- 建立 `relation_type = SIMILAR_TO` 的高权重软边，关联两个节点
- Mind 在未来的 Deep Dream 中自行分析这对相似节点，决定是否融合
- 融合后的节点携带双方 `source_helix_id`

## 时代凝章

用户长期失联（如超过 100 年）时，Mind 不执行数字火化。取而代之的是**时代凝章**——不是销毁，而是尊重性封存。

### 凝章流程

1. **不可变快照**：将所有与该用户相关的数据（L3 情景记忆、社会关系网、用户画像的当前版本）打包为一个不可变的 IPLD DAG 快照，生成唯一的 `epoch_cid`
2. **极致压缩存档**：使用最高压缩比的算法，移入廉价的不可变存储层，从日常检索引擎和代谢管道中完全移除
3. **留档铭牌**：在本地保留一个极小的档案索引（< 1KB），包含 `epoch_cid`、监护人名称、时间跨度、关系摘要
4. **铭牌对后世可见**：后世 Helix 可只读访问铭牌，作为家族的考古凭证

### 凝章后状态

- L3 情景记忆：完整保留在压缩快照中，不可访问但永不删除
- 用户画像：进入凝章状态，铭牌永存，不再参与日常推理
- 社会关系网：关系边进入凝章快照，不再作为活跃图谱存在
- `entity_type` 信息：永不可混淆——即使关系被凝章，物种边界永远清晰

## 沙箱 Review 安全公约

联邦 Review 依赖 LLM 审查外部节点的逻辑自洽性。为防止恶意节点通过构造特殊内容进行提示词注入攻击，所有进入沙箱的外部节点必须遵循以下安全公约：

1. **零上下文污染**：LLM Review 时，待审节点内容被封装在独立的 System Prompt 分区中，与 Reviewer 的系统指令物理隔离。
2. **纯判别输出格式**：Reviewer LLM 的输出被强制约束为结构化 JSON。任何非 JSON 输出、包含指令性文本的输出、或字段缺失的输出，直接判定为审查失败。
3. **双盲验证**：对同一外部节点的 Review 使用两个独立的 LLM 实例。若两者的 `logically_coherent` 判定不一致，该节点标记为存疑，不自动合并。
4. **沙箱节点禁止输出**：任何处于沙箱状态的节点，其 `suggested_actions` 字段在合并前被强制清空。
5. **高风险节点标记**：涉及系统级操作的知识节点，即使通过逻辑自洽性审查，也必须额外标记为 `high_risk: true`。

## 共享知识树免疫公约

共享知识树不依赖经济激励或拜占庭容错协议来保证安全。其免疫力来源于以下机制：

1. **来源多样性要求**：在提升外部 L2 节点的本地共识权重之前，Mind 应验证该知识来源于至少 N 个独立 Helix 实例（N 可配置，默认 3）。
2. **物理实证门槛**：对于涉及物理世界操作的节点，在效能权重 `𝒰` 超过 0.5 之前，必须经过至少一次本地沙箱或安全环境中的实证验证。
3. **来源回溯与信用降级**：任何导致本地实证失败的外部知识，其来源 Helix 的 `source_helix_id` 被记录在本地信用降级日志中。
4. **认知拒绝服务防护**：当单个外部来源在短时间内产生大量辩证边指向本地高共识节点时，Mind 自动限制该来源节点的沙箱审查速率。
5. **不可验证知识的保守策略**：对于"验证代价为生命"的极端场景，此类知识永远保持 `high_risk` 标记，且 `𝒰` 权重上限锁定在 0.3，永不提升为显性常识。

**哲学底线**：Helix 不是区块链。它不靠代币质押、不靠经济惩罚、不靠拜占庭容错协议。它的免疫力来自"信用由他证 + 来源多样性 + 物理实证门槛 + 高风险保守策略"。足够好的安全，不需要完美的数学证明。

## 网络层外包

Helix-Mind **不写一行 P2P 代码**。联邦 DAG 共享的网络层完全外包给 Rhizax。

### 分工

| 组件 | 职责 |
|:---|:---|
| **Helix-Mind** | 产生 L2 知识、打包为 IPLD 格式、写入本地共享目录 |
| **Rhizax** | 监听共享目录、Pin 到 IPFS 生成 CID、通过 Gossip 网络广播信标 |
| **远端 Rhizax** | 接收信标、验证签名、通知本地 Mind |
| **远端 Mind** | 决定是否拉取、沙箱 Review、Merge |

### 信标格式

```
Knowledge Evolution Beacon {
    type: "DAG_UPDATE"
    cid: string          // IPFS 内容哈希
    signature: bytes     // Ed25519 签名
    l0_hash: string      // 发送方当前 L0 哈希
    timestamp: uint64    // 逻辑时间戳
}
```

**Mind 是真理的生产者和审查者。Rhizax 是真理的物流商。**
