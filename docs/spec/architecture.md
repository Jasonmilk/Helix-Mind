# 架构法则

## 法则 01：编排优先，拒造实体

Mind 是记忆中枢，不是全能框架。它只负责知识的存储、检索、代谢、轮回。任务编排、意图路由、工具调度是 Anaphase 的职责。

**Mind 不做的**：不直接调用 Tentacle 执行动作，不替代 Anaphase 做编排决策。不实现 HTTP/WebSocket 客户端——CAP 协议交互通过 Anaphase 完成。

### 子条款：Mind 不执行，只建议

Mind 的职责是给出基于当前知识的最佳认知输出。如果认知输出中需要计算、查询外部数据、操作物理设备，Mind 应在输出中携带 `suggested_actions` 字段，声明推荐的工具类别（如 `python_interpreter`、`web_search`、`cli_command`），但不执行它们。

工具的实际调用由 Anaphase 通过 CIS 静态映射表完成。调用结果作为新一轮 `HelixQuery` 的上下文传入，形成工具链闭环。

### 子条款：数据库独占所有权

磁盘上的所有持久化数据（SQLite、Parquet、JSONL 等）物理上仅由 Helix-Mind 进程独占持有并锁定。任何其他组件（包括 Anaphase）不得直接读写这些文件。所有知识访问必须通过 Helix-Mind 暴露的 gRPC 接口进行。

## 法则 02：极简复用，外包生态

每一行新增代码必须有不可替代的理由。能用现有工具解决的，不自己造轮子。

**Mind 外包的功能**：
- P2P 网络 → Rhizax
- KV 缓存 → Helix-Callosum
- 本地推理 → Tuck
- UI 渲染 → Cellrix
- 意图解析 → CIS
- Agent-UI 交互 → CAP
- 工具执行 → Helix-Tentacle
- 任务编排 → Anaphase
- LLM API 调度 → FlowModus

**生态级极致复用原则**：
- **工具说明书单源复用**：彻底消灭 Anaphase 本地的 YAML 工具配置。Tentacle 的 `.manifest.json` 是全生态唯一真理源。
- **脑区推理硬件单核复用**：运行时 0-Token 寻路（SA-Core 纯数学矩阵乘法），只有 Anaphase 的 Think 阶段和 Mind 的睡眠管道被允许调用 LLM。
- **已见熵过滤器索引复用**：Callosum 直接读取 Mind 内存拓扑层中的活跃 Node ID 列表生成布隆过滤器，无需任何数据库读写。
- **小脑反射环沙箱复用**：彻底复用 Tentacle 的 WASM 运行时。Helix-Mind 在深睡期提炼的反射策略，输出为轻量 JSON/TOML 决策矩阵配置文件。
- **记忆轨迹事件流溯源复用**：Anaphase 的 HXR 日志就是 Mind 的 L3 情景记忆，一份 JSONL，既是审计日志又是记忆档案。

## 法则 03：原子边界，单一职责

Mind 内部模块边界清晰：

| 模块 | 职责 |
|:---|:---|
| `ingestion` | 摄入：Tentacle 抓取 / Anaphase 推理 / 想象力生成 |
| `digestion` | 消化：Micro-Sleep 去重合并、认知失调检测 |
| `absorption` | 吸收：Deep Dream 提炼 L2、隐私洗脱 |
| `storage` | 存储：DAG 读写、索引更新、深冷归档 |
| `forgetting` | 遗忘：Heat 衰减、隐性基因归档、突触切断 |
| `recycling` | 复用：高频节点推送 Callosum 静态前缀池 |
| `reincarnation` | 轮回：生命周期管理、传承晶体生成 |

### 双态内存引擎

- **热态（内存拓扑层）**：运行时在内存中维护轻量级图拓扑索引，仅存 Node ID、Edge Weight、Relation Type。所有图扩散、无向游走、拓扑排序、回环检测在内存中极速完成。SA-Core 能量扩散算法在此层执行，通过稀疏矩阵乘法在微秒级完成寻路，0 Token 消耗。
- **冷/温态（持久化层）**：SQLite + Parquet 负责属性点查、批量统计、持久化落盘。内存拓扑层拿到目标节点 ID 集合后，由持久化层进行高吞吐的属性填充。
- **同步策略**：写操作同时更新内存拓扑和持久化层。读操作仅访问内存拓扑，拿到 ID 后回查持久化层获取完整内容。
- **严禁在 SQL 层面执行深度 > 2 的递归 CTE 图遍历。**

## 法则 04：管道通信，协议松耦

Mind 对外仅通过定义的 gRPC/Protobuf 接口通信。所有输出通过标准流或 API 返回，不使用内存对象传递。

**Mind 的对外契约**：详见 `docs/spec/api.md`

**共享知识树同步策略**：
- 本地检索无结果（困境 Stage 2）→ 按需向 Rhizax 查询语义相似的 L2 节点 CID
- 代谢期（Micro-Sleep / Deep Dream）→ 检查本地引用的共享节点有无新版本
- 用户显式请求探索某领域 → 拉取该领域的高共识节点
- 联邦信标到达（被动接收）→ 沙箱接收，Mind 决定是否拉取内容
- **绝无定时轮询、心跳探测、全量同步**

# 回环控制与软着陆

## 回环哲学

**允许局部回环，强制全局无环。**

- **严格 DAG**（L0、L1、L2、L3、传承晶体、用户画像、人物画像）：绝对无环。
- **根系网**（社会关系网、项目管理网）：允许逻辑上成环的连通图。受三大熔断器限制。

## 四象限回环控制矩阵

| 层级 | 回环策略 | 终止行为 | 提炼机制 |
|:---|:---|:---|:---|
| **L0/L1 基因锁** | 绝对无环 | N/A | 永不提炼 |
| **L2 经验层** | 认识论螺旋 | 路径反向传播 + 权重微调 | Deep Dream：LLM 模式分析 → 经验规则 |
| **L3 情景层** | 线性时间轴，不可回环 | 软着陆五阶段协议 | Micro-Sleep：合并去重；Deep Dream：提炼为 L2 |
| **根系网** | 允许复杂环路 | 三大熔断器限制 | 只归档，不提炼 |

## 回环熔断三大机制

### 熔断器一：全息轨迹去重

每次图遍历生成全局唯一的 `trace_id`。在同一 `trace_id` 的遍历路径中，任何节点最多被访问一次。

### 熔断器二：能量衰减定律

遍历动力来自 `EnergyContext.token_budget`。每跨越一条软边，扣除一定能量值。软边权重在连续传递中相乘衰减。当能量归零或权重衰减到阈值以下时，遍历物理终止。

### 熔断器三：TTL 滚动清理

对于项目管理网，超过配置阈值的未闭环软关联，静默降级到冷存储。

## 软着陆五阶段协议

计数器归零触发的不是删除，而是结构化的收敛与提炼流程。

1. **状态快照**：将当前节点的完整状态序列化为 L3 事件节点
2. **路径反向传播**：惩罚死胡同边权重，更新探索时间戳
3. **收敛火花检测**：检查终止节点是否与已有节点产生"意外共鸣"
4. **稀疏提炼**：Deep Dream 时聚合多个终止事件，生成 L2 经验节点
5. **归档决策**：高唯一性标记锚定，重复则合并，其余进入隐性基因库

**计数器归零不是终点，而是提炼与归档的起点。**
