# L1 自画像

## 定义

L1 是 Helix-Mind 对自身的认知镜像——它记录自己对什么擅长、卡在哪里、何时需要调用想象力。L1 随每一次轮回重置，旧版本归档为 `LifeRecord`，不参与检索。

## 内容

| 维度 | 说明 |
|:---|:---|
| 能力评估 | 对各类任务的熟练度与成功率 |
| 瓶颈标记 | 当前认知模式的局限与盲区 |
| 想象力阈值 | 何时允许触发想象力模式 |
| 元认知状态 | `impasse_depth` 历史、检索策略偏好 |

## 与元认知的关系

L1 是元认知知识的持久化存储：

- **元认知知识**：对自己认知能力、任务难度、策略有效性的认知
- **元认知监控**：对当前认知过程的实时监测（`impasse_depth`、检索结果置信度）
- **元认知控制**：根据监测结果调整认知策略（模式切换、代谢触发）

## 每世重置

- 轮回时，L1 节点全部归档，新一世从零开始书写
- 元认知知识可通过 L2 私有经验跨世传递（但不强制继承）
- 记事本 DAG 随轮回清空

## 工程映射

L1 节点类型为 `L1`，存储于 DAG 中，检索时优先加载。与 L0 基因锁不同，L1 是动态的、每世刷新的。
