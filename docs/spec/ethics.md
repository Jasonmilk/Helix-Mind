# 极致节能的工程映射与伦理底线

## 植物性设计

| 植物特性 | Helix-Mind 映射 | 实现位置 |
|:---|:---|:---|
| **光合作用** | lodestone L0/L1 确定性投影，零 Token 消耗 | lodestone-md |
| **落叶回收** | 睡眠管道去重合并 | Micro-Sleep |
| **种子休眠** | 隐性基因库 | 隐性基因库 |
| **根系网络** | 联邦 DAG 共享 | Rhizax + 联邦共享 |
| **向光生长** | 熟练模式 Beam Search | SA-Core |
| **年轮积累** | 世代计数 | 命名与世代 |
| **枯萎** | 向死而生 | 生命周期协议 |

## 能量意识原则

**每一个功能必须先回答"它的能耗是多少"。**

| 操作 | 能耗级别 | 优化策略 |
|:---|:---|:---|
| lodestone 投影命中 | 零 | 高频知识永久驻留（浓缩主线 DAG） |
| SA-Core 内存拓扑层矩阵扩散 | 极低 | 稀疏矩阵乘法，0 Token |
| SQLite 属性点查 | 低 | 批量查询 |
| 向量语义检索 | 中 | 仅逻辑支撑模式启用 |
| LLM 推理 | 高 | 仅 Deep Dream、认知失调、联邦 Review 时调用 |
| 想象力模式混沌游走 | 极高 | 必须显式授权 |

## 深冷存储

L3 情景记忆永不物理删除。过期后从热数据区移入深冷存储。请求删除时执行突触切断与遗忘标记，原节点归档保留。解冻操作消耗大量 Token 和 I/O，需显式确认。

## 资源回收策略

七级回收优先级。永不回收清单包括 L0 基因锁、传承晶体草稿、自画像、用户画像（CREATOR_IMPRINT）、承继关系、时代凝章铭牌。
