# 人格侧写图谱

## 图谱总览

四类与"人格"和"关系"相关的知识：

```
人格侧写图谱
    ├── 用户画像 (User Persona) — 造物主的印记，CREATOR_IMPRINT
    ├── 自画像 (Self-Portrait) — 自己的镜子，每世重置
    ├── 人物画像 (Contact Persona) — 对他人的认知
    └── 人际关系网络 (Social Graph) — 关系的编织，根系网
```

## 用户画像：造物主的印记

- **永不删除**：任何情况下不得删除
- **跨轮回保留**：轮回时以只读方式继承，新一世可追加新观察
- **证据固化**：临终倒计时期间，`evidence` 转为 `abstract_provenance`
- **绝对隐私，永不共享**：即使用户授权共享 L3 记忆，用户画像也不可外泄

## 自画像：自己的镜子

每世重置。旧版本归档为 `LifeRecord`，不参与检索。记事本随轮回清空。元认知知识可通过 L2 私有经验跨世传递。

## 人物画像：对他人的认知

跨轮回保留。非承继关系在新一世进入隐性基因库。`entity_type` 永不可混淆。

## 人际关系网络：关系的编织

根系网结构，允许双向环。承继关系（`is_legacy=true`）跨世保留。百年清理规则明确区分可清理与不可清理的关系。

## 时代凝章铭牌

当用户长期失联或监护人发生更替，所有人格侧写数据进入时代凝章。铭牌只读，永不删除。
