# 认知工艺（Cognitive Craft）规范 v1.1

> **版本**：v1.1（2026-08-28）
> **审查**：吸收 Gemini 审查补丁 7 项 + 豆包严肃审查 B1/B2/B3 三项修正
> **决策锚**：ADR-0021（Active）
> **归属**：Mind 核心域（检索策略属于 Mind，VISION 原则 7）

## 一、定位

认知工艺是 Helix 的**"如何思考"系统**：根据问题复杂度与类型，自主选择最合适的思考方式；复杂问题拆解为多道独立工序，最后整合为高质量答案；通过睡眠复盘与随机变异维持思维多样性，防止路径依赖。

**一句话**：先判断要不要想得多，再决定怎么想，最后把想法合起来。

## 二、原子约束（不可协商）

1. **Mind 不直连 LLM**（Z2 锁死延续）：编排是纯逻辑，执行经 ADR-0017 `CognitiveService` 注入。
2. **门控 0 Token**：System 0 只用规则 + FTS5 bm25 相关度，不引入向量依赖。
3. **原始输入不可裁剪**：MSC 中的原始输入原文是事实锚点，只裁剪历史草稿。
4. **合题是确定性操作**：不是 LLM 自由发挥，输出条件化命题。
5. **成功率用确定性信号**：任务完成标志/重试率，禁用 LLM 自我评分（信用由他证）。

## 三、System 0 启发式门控（B2）

在启动认知工艺前，先执行轻量门控判断，避免"为了判断是否简单，先花 500 Token 编排"的递归悖论。

| 门控信号 | 实现 | 成本 |
|:---|:---|:---|
| 规则匹配 | 问题长度、关键词、历史相似匹配 | 0 Token |
| **FTS5 bm25 相关度阈值** | 与已知简单问题池的命中分数 | 0 Token（M-01 已有） |
| 用户意图标签 | 显式"帮我深入分析" → 跳过门控 | 0 Token |

**递归禁用**：门控阶段严禁调用认知工艺本身。

**与 ADR-0010 划界**：预算路由（外部前置）决定检索**扫描范围**（相态）；System 0（Mind 内）决定思考**深度**（是否触发工艺）。两者正交。

## 四、工序 × 模式

### 4.1 工序（认知操作算子，5 种）

| 工序 | 作用 | 适用场景 |
|:---|:---|:---|
| 结构性 | 分析边界、依赖、架构 | 系统设计、架构规划 |
| 批判性 | 找漏洞、盲区、假设错误 | 方案审查、风险评估 |
| 创造性 | 新方案、替代路径 | 头脑风暴、创新探索 |
| 情境/意图解析 | 理解需求、情绪、上下文 | 用户沟通、团队协作 |
| 元批判 | 审视思考过程本身 | 复盘、自我改进 |

### 4.2 运行模式（与工序正交，3 种）

| 模式 | 角色 | 使用场景 |
|:---|:---|:---|
| 熟练 | 贴地飞行，沿 DAG 铁轨 | 日常、低风险、熟悉任务 |
| 锚定 | 基于 DAG 锚点，适度扩展 | 中等复杂度、需验证 |
| 想象力 | 脱离 DAG 自由发散 | 创意、探索、未知领域 |

## 五、编排器流程（含独立会话隔离）

```
主会话（问题提出）
    │
    ▼
1. System 0 门控
    ├── 低价值/简单 → 熟练模式直接输出
    └── 高价值/复杂 → 触发认知工艺
    │
    ▼
2. 主会话编排工序（组合 + 顺序 + 各工序模式）
    │
    ▼
3. 独立会话执行
    ├── 每道工序独立会话
    ├── 注入 MSC：[原始输入原文] + [工序专有 Prompt] + [全局约束 Schema]
    ├── 严禁子工序横向引用中间草稿
    └── 共享 trace_id，上下文隔离
    │
    ▼
4. 主会话收敛（黑格尔辩证协议）
    ├── 正题：结构/创造工序核心主张
    ├── 反题：批判工序证伪边界与风险
    └── 合题：条件约束下重构（保留正题 + 注入反题防御 → 条件化命题）
    │
    ▼
5. 输出 + 可审计归档（完整 trace_id 链路）
```

## 六、Token 预算熔断

| 防护 | 默认值 |
|:---|:---|
| 最大子工序数 | 5 |
| 单工序 Token 上限 | 全局预算分配 |
| 总 Token 预算 | EnergyContext（ADR-0010） |
| 子工序超时 | 30s（超时终止，返回部分结果） |

## 七、抗僵化

| 机制 | 说明 |
|:---|:---|
| 睡眠复盘 | Deep Dream 窗口内"非熟练模式检视"（强制锚定/想象力，防假复盘），不阻塞主循环 |
| Bounded ε-Greedy + EMA | 突变率 3%-20%，EMA 平滑成功率 |
| 多样性路径池 | L1 自画像维护 2-3 条"曾有效但非最优"备份路径 |

## 八、与现有机制的关系

| 现有机制 | 关系 |
|:---|:---|
| SA-Core 检索 | 工艺的输入来源（工序处理原材料） |
| 认知循环（Micro-Sleep/Deep Dream） | 工艺的时间窗口（睡眠复盘在 Deep Dream 执行） |
| L1 自画像 | 工艺的记忆体（策略效能表 + 多样性路径池） |
| trace_id | 工艺的审计线（全链路可追溯） |
| EnergyContext | 工艺的预算输入（熔断依据） |
| ADR-0017 CognitiveService | 工艺的执行通道（三适配器） |

## 十、风险与回滚

| 风险 | 缓解 |
|:---|:---|
| 增加复杂度 | Phase 1 只定稿；Phase 2 最小原型 |
| Token 增加 | System 0 只对高价值触发 |
