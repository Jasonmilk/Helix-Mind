```

· anaphase：main 78 笔（最早 2026-03-19）· 分支 412 笔（最早 2026-04-20）

   **且解决的不是我们的问题**。**真正的问题是【主干抉择】：哪条历史是主干？**
⇒ **这是【升级】类决定**（动权威卷级别的方向），**必须人定**（见下）。
```
