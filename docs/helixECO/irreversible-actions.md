# 不可逆动作清单（草稿 · Draft）

> **为什么现在必须有**：目标从「研究」变成「金融级：可购物、可汇款（HITL）」。
> 之前判据对齐时我删掉过一条「动作类别为 `CRITICAL` 即红」的检查，理由是
> 「生态无动作风险分级 ⇒ 判据恒绿」。**那个判断要修**：不是删判据，是**先建清单，判据才有对象**。
>
> **不借协议词**：`CRITICAL` / `HARD_OVERRIDE` 是外部协议（PFP-xCF14 / BIND-19）的词汇。
> 借了就要再做一次「协议枚举 ↔ 生态动作」的映射 = 第二份真相。本清单是本生态自有词汇。
>
> **真值源**（共识 C-009，待拍）：后果探测，两个维度**任一命中即升档**——
> ① 物理执行面 ② 不可逆·资金能力面。依据 ISO 13849-1 的 S 参数：**等级由后果定，不由机制定**。

## 草稿（v0 · 待审）

| # | 动作族 | 为什么不可逆 | 后果维度 | 能否进反射弧 | 必需的门 |
|---|---|---|---|---|---|
| I-1 | 资金转出（汇款、支付、转账指令） | 到账即不可撤回，只能追讨 | 资金 | **否（永久）** | HITL + 双人复核 + 2PC |
| I-2 | 购物/下单（含自动续费、订阅） | 产生扣款义务与合同 | 资金 | **否（永久）** | HITL |
| I-3 | 凭据/密钥轮换与吊销 | 旧凭据失效不可回退（对方已更新则不可逆） | 资金+可用性 | 否 | HITL，且需可回滚证明 |
| I-4 | 数据删除（含审计链、映射表） | append-only 语义被破坏即永久 | 记录完整性 | **否（永久）** | HITL + 双人 |
| I-5 | 对外发布（代码、公告、消息） | 已被第三方读到即不可撤回 | 声誉/法律 | 否 | HITL |
| I-6 | 物理执行（机器人动作、阀门、机械输出） | 物理世界无 undo | 物理 | 否 | HITL + 硬件级互锁 |
| I-7 | 权限授予/扩权（含 agent 委托） | 一旦被用即产生既成事实 | 授权面 | 否 | 人（委托根），且禁止自我升级 |

## 待定（诚实标注未定项）

- **「可撤销」判据尚缺**：现在只有人工判断。候选自动判据 = 动作是否留下外部已生效副作用（对方系统已收到），
  但这需要按动作族逐个给出可核事实，**尚未做**。
- 与本清单配套的判据**还没写**（先有清单，判据才有对象；顺序不可颠倒）。
- `I-1/I-2` 的「双人复核」在生态里**没有实现**（无权限系统）⇒ 现状只能落成 ADR 条款 + 人工纪律。

## 明确不做

- 不借 `CRITICAL`/`HARD_OVERRIDE` 做生态判据。
- 不让任何 I-x 进反射弧（含「训练后学会的反射」——候选不等于已授权，C-008）。
- 不把本清单做成「第二份动作枚举」：动作**类别**从 `Tuck` 的政策矩阵派生，本清单只增加「不可逆」这一列。
