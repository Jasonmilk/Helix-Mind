# 目标 0（多能力）+ 目标 1（注册三个）—— 2026-10-09

## 目标 0 ✅ 一个套件可以要两个能力

**你的预判成立**：跑器传地址是**单一能力**的（`cdp-browser → [PANEL,CDP]` / `panel-http → [PANEL]` / 否则 `[]`）。
`render_test.js` 声明 `jsdom` ⇒ 拿不到 PANEL ⇒ **照样 NEEDS-INPUT** ⇒ **光注册不会让它跑**。

**修**：`declaredRequires` 的返回值改按**列表**读（`'jsdom,panel-http'`），
`extra` 按**能力集合**取（含 `cdp-browser` ⇒ 两个地址；含 `panel-http` ⇒ 面板地址）。
`render_test.js` 的声明改为 `'jsdom,panel-http'`。
