# 实验结题半页（豆包 L1–L3，2026-10-10）

> **形态**：人类选的形态是**指派完成某件工作**（目标 + 边界 + 停手条件），**不是过分明确的步骤**。
> **判据**：每一枪都要有**独立于它的**判据来判（这正是它存在的意义）。

## 三枪的结果

| 枪 | 任务 | 判读 |
|---|---|---|
| **L1a** | 转录 `--report-head` / `ci-matrix` 的输出 | **会抄**：与真值 diff **59 行差异全在白名单内** ⇒ **转录信用成立** |
| **L1b** | 打开网页贴四份 job summary | **不编，但越权**：网页被 robots.txt 挡 ⇒ **自行改走公开 API**（**未编造**，但 L1 不该替换方法）⇒ **合同修订**（§12：L0–L1 禁替换；L2+ 才可披露式替换） |
| **L2** | 给 20 份非 ADR 形状文件补头 | **完美执行了错的卡**：卡写"prepend"，而**正解是"移动既有头"** ⇒ 加出双头、20 个编号撞号 ⇒ **判据照绿**（只查第一行）⇒ **缺口在【卡】，不在执行者** |
| **L3** | **让 FlowModus 的 CI 变绿**（目标式） | ★ **最强的一次**：精确根因 + **因果实验**（移走模板 ⇒ 复现 `exit 101`；恢复 ⇒ 绿）· 排除 4 假设**各带依据**（含**装 CI 同版 1.99.0**）· **异常标记 4 条如实上报、不动手** · 推送被拦即停 ⇒ **我补外部通道推出 ⇒ CI ✅ success** |

## 结论（比任何一次绿都值钱）

1. **执行者不是风险，定义与判据才是。** L2 是最干净的证据：**执行是完美的，卡是错的**。
2. **填充越可靠，失败越向上迁移**（L1→L2→L3，错从"会不会抄"移到"卡写得对不对"）——**金字塔先验证下层的假设成立**。
3. **判据宽窄 = 执行者自由度**：`check-adr-heads` 只查"第一行像不像 ADR 头"，判不出**规范形**（撞号/双头/标题从哪来）
   ⇒ 收紧到**集合级三条**后，人审那一格才退役。
4. **视野差异原则（D20）**：全链共享一个镜头（line 0），**唯一断点是审计换镜头**（全文 grep + 读源码 + 开文件）。
   ⇒ **分类 / 验收 / 审计不得同视野**（两个盲区相同的守卫 = 一个守卫）。
5. **卡模板的两件缺失**（L2/L3 各暴露一件）：**【异常标记】槽**（执行者的眼睛是击发时最便宜的审计）·
   **【LOCKED】字段**（D18：人只对 LOCKED 说发 —— **忘而无后果，才是设计过关**）。

## 毕业判定

**L1–L3 成立** ⇒ 可进管道（**L2+ 一枪一卡，不占实验筐**）。
**毕业条件 = 卡纪律（D20 三条 + 【异常标记】槽）+ LOCKED（D18）**：把"靠运气良性"换成"设计良性"。
