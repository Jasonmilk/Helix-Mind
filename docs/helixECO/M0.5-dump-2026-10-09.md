### 3.1 72.5% 孤根**不是缺陷**

全库 **462 个 period 只来自 56 个不同 `job_id`**：

| `job_id` | period 数 |
|---|---|
| `run-233a86e49afbc98c` | **219** |
| `run-f911e602dcba3236` | 85 |
| `run-4b37bf495fca46db` | 85 |
| `run-d46f06724ec6995e` | 11 |
| 其余 52 个 | 62 |

⇒ **前 3 个 `job_id` 就占 389 / 462 = 84%**。名字侧车印证：`S303 HTTP 判据:带锚点`、
`只回答两个字:你好`、`hi` 被反复提交。

**同一个问题被重问 219 次 ⇒ 219 个独立 period，每个都是根，这是 `ADR-0041` 的正确答案**
（身份与输入解耦）。把根占比当缺陷是把"复问"误读成"丢链"。

### 3.2 因此：72.5% **不能**用作 M7 的解冻基线

M7 条件写的是「139 个 period 孤根数 83 → 可接受」。该条件建立在**已消失的语料**上。
**在 84% 是重复探针的库上谈"孤根率可接受"，是把两种数据混为一谈。**

> **⇒ 差分实验必须用「新的、多样的」对话**（M0.5 步骤 1–4），
> 探针语料只能证明"覆写已关"，证明不了"链能不能连起来"。
