## 三、⚠️ 我自己污染过一次对照（记录，并撤回那个读数）

第一次测量在**同一次页面加载里连调两次** `loadWindow`（先默认、后 period），得到：

```
default: events array[407] jobs array[24]
period : events array[407] jobs array[1]     ← events 相同！
```

我据此一度怀疑"只改了一半"。**⇒ 那个读数是假象**：第二次调用拿到的是第一次留在 **tape** 里的内容
（`jobs` 正确变成 1，因为它是新算的）。**改成每次 reload 后只调一次，读数就干净了。**
**⇒ 撤回那个怀疑。教训：同一个进程里连调两次同一个"会累积状态"的函数，第二次不是对照。**
