# 目标 1 判定：detail 区显示的是**血缘路径**，不是那一段自己 —— **既非 A 也非 B**

> 2026-10-09 ｜ 人类真实使用反馈（11:25–11:26）。按人类要求先判 A/B，结论是**第三个**。

## 一、事实（读代码，不是猜）

```js
// Cellrix:web/assets/panel_tree.js:99
function selection(tree, id) {
  var n = tree.byId[id];
  return { kind:'node', id: id, parent: n.parent,
           children: n.children.slice(),
           context: ancestorClosure(tree, id),   // ← 祖先闭包 = 血缘路径
           /* The period's own facts are pulled by the caller ONLY when this node is selected */
           rows: null };
}
```

⇒ **点一段 ⇒ detail = 这一段 + `ancestorClosure`（全部祖先）+ children。**

人类看到的三处「不对」，逐条对上：

| 人类看到 | 对应 |
|---|---|
| `Turn 1 · run-78175309ad0c2285` = **几天前的旧句** | **血缘链的根**（`ancestorClosure` 的第一个） |
| `run-f911e602dcba3236 ×14（Turn 3–17）` | 这条链的**根段**，14 轮都在它里面 |
| 混着 5 个不同 period | **祖先链本来就是多个 period** |
| `18 turns / 291 steps 是全局的` | 不是全局 —— 是**这条链的并集**（祖先 + 自己 + 子） |

⇒ **列表里最新那句"不在 detail 里"** 也解释得通：detail 从**根**开始列，最新的那句在**尾部**。

## 二、A / B 都判否

- **A（旧面板 / 修复未生效）**：**否**。症状与 `ancestorClosure` 的契约**逐条吻合**；这是**现行代码的既定行为**（`Cellrix:ADR-0021` 明写 *"the window is the LINEAGE PATH"*），不是旧页面残留。
  （仍然：重启面板才能拿到"默认不选中"——那条**另算**，与本症状无关。）
- **B（没有选中 ⇒ 不过滤 ⇒ 显示全局）**：**否**。过滤是存在的，只是**过滤的粒度是"血缘路径"**，不是"这一段"。
  人类的判据（"点两张卡看到同一份列表 ⇒ 没过滤"）**应判不成立** —— 两张不同的卡给两条**不同**的链。

## 三、真因：`ADR-0047` §3.3 记过的**混用**

| 概念 | 定义 | 该服务 | 现状 |
|---|---|---|---|
| `lineage_path`（血缘路径） | 祖先链 | **上下文加载**（继续对话时注入什么历史） | ✅ 正确、被 `ADR-0021` 采用 |
| `slice`（切片） | 从选中根出发的**可达子图** | **展示 + 继续** | ❌ **展示层用的是血缘路径** |

**⇒ 这就是我 2026-10-09 在 `anaphase:ADR-0047` 里判定为"混用"的那一处**，当时我写：
> *"若当前 `chainJobIds` 仍被展示层调用，那就是混用了两个概念 —— 这才是要修的点。"*

**今天它在真实使用里现形了**：展示层显示的既不是"这一段"（那是节点），也不是"这一段的切片"（可达子图），
而是**"这一段 + 它的祖先"** —— 一个**为上下文加载设计的窗口**被当成了展示窗口。

## 四、处置（设计已定，本轮**未实现** —— 预算用尽）

**展示必须按 `slice` 过滤**，而不是按 `lineage_path`：

1. **点开 period X ⇒ detail 只含 X 的可达子图**（`slice(X)`），不是 `ancestorClosure`
2. **每一行必须标明它属于哪个 period**（人类这次的证据正是因为 period 混在一起才难读）
3. **没有选中 ⇒ detail 为空或具名空态**，**不得**是"全局"或"某个祖先链"
4. **变异**：把 `ancestorClosure` 放回展示 ⇒ 判据 ①②③ 必须红

> **边界（人类已定）**：`lineage_path` **仍然**是正确的**上下文加载**窗口，`ADR-0021` 不该被推翻 ——
> 要改的是**展示层用哪一个**，不是把血缘路径本身改掉。

## 五、人类新增纪律（本轮，与第 13 条同族）

> **视图的过滤不得依赖"选中态"的存在。**
> 空选中 ≠ 无过滤 —— 那是"没说要什么"被读成了"什么都要"。
> （第 13 条：一个状态的**缺失**被读成了一个**不同的语义**。）
