## 一、中心命题

平面题目叫「生态收敛」，但真问题不是"组件太多"，而是：

> **数据流的 DAG 断了 —— 会话（经历）在存储、窗口、展示三层各被推导一次，三层互不一致。**

所以收敛的**中心**是**会话 DAG 可证连通**，不是"摘掉哪个组件"。
M2 排在 M5 之前、UI 排在最后、FlowModus 只是顺带降噪 —— 都是这条中心线的推论。

## 二、一个病，八处分岔：同一事实多份推导

| 现象 | 违背 | 事实锚点 |
|---|---|---|
| 证轨自己 `fetch('/api/events?job_id=')` | 极致复用（第二份数据源） | `prove_track.js:124` |
| `subscribers` 与 `targets` 并存 | 极致复用（同一问题两份实现） | `assembly.js:168/:171` |
| DOM 契约清单是手抄快照 | 0 硬编码（事实的第二份副本） | `docs/dom-contract.md` |
| `job_id` 派生自输入内容 | 确定性 ≠ 稳定 | `K15`（→ `ADR-0041`） |
| 窗口用「血缘路径」，展示要「可达子图」 | 一个词两个用途 | `anaphase:ADR-0047` |

**共同形态**：同一事实被推导两次以上，然后两份读数在时间里分叉。

## 三、三处取舍的理由

### 3.1 M2 排在 M5 之前

DAG 断裂的五个成因（A1–A5）**全在 Anaphase / Cellrix 侧**，与 FlowModus 无关；
而 `ADR-0041` 已经躺了 21 天。

**M5 摘掉 FlowModus 只是把「全乱套」变成「只有一处乱」—— DAG 不会自己好。**

### 3.2 M3 的四条测试是"把已测过的数字变成断言"

12/139、5/51、83 孤根、8 个多组 `turn/start` —— 这些不是新工作，
是把 2026-09-17 已经量过的读数钉成断言。**但它们全部作废了**（见 §四）。

### 3.3 M7 是条件触发的，不主动启动

最硬的解冻条件：**139 个 period 的孤根数 83 → 可接受**。
**不可能在 60% 坏掉的数据上做出好 UI** —— 这是人类 v1.99 写的「那个旧判断是误诊」
（"分组有 83/139 输入不可用，当然失败"）。

## 四、信息腐烂：本轮最大的教训

**人类的判断依据是 `ECOSYSTEM.md` v1.99，日期 09-17。今天的实际日期是 10-08。**
而 **`ADR-0041` 已于 09-18 落地**（`519da1f` + `eba9ff3`）。

⇒ **三周前的快照下的判断，前提已失效。** 这正是系统自己诊断过的「信息腐烂」。

### 4.1 连锁影响

| 原计划 | 修正后 |
|---|---|
| M2「从零落地 `ADR-0041`」 | **M2 = 验收 + 补缺口** |
| M3 四条基线（12/139、5/51、8 文件、83 孤根） | **全部作废，必须重测** |

### 4.2 由此推出的关键问题

> **`ADR-0041` 于 09-18 落地，而 10-08 仍然痛。**

只有三种可能：

1. `ADR-0041` **没修完**（有缺口）
2. 有 **A1–A5 之外的新成因**
3. 痛感来自 **FlowModus 那一半**（与 DAG 断裂是两个独立的病）

**三者导致完全不同的后续动作，而现在无法区分。** ⇒ 所以要有 M0.5。

## 五、M0.5 差分实验（零代码，M2 之前必须做）

### 5.1 步骤

```
1. 摘掉 FlowModus（走 Anaphase → Tuck → 上游）
2. 连开 5 轮新对话 + 1 次旧会话续接
3. 导出 /v1/sessions，dump 全部 period 的 parent / first_ts
4. 接回 FlowModus，同样操作，再 dump 一次
5. 对比两份图的差异：节点数 / 孤根数 / 非 id 父 / 时间戳单调性
```

### 5.2 产出

**一张对照表**。它决定 M2 是"补缺口"还是"查新因"。
**成本**：零代码，只跑 + 只读。但它是 M2 唯一可靠的起点。

### 5.3 两种结果的判读

| 结果 | 判读 |
|---|---|
| 两次 dump **无差异** | FlowModus 不在 DAG 链上 → 病在 Anaphase/Cellrix（M2 范围），痛感成因是 1 或 2 |
| 两次 dump **有差异** | FlowModus 在链上 → 选项 3 成立，痛感是**两个独立的病**，M5 的优先级要重排 |

### 5.4 存档（**硬要求**）

dump **不能只留在终端里**，进 `docs/` 或 GROWTH 归档 ——
它是后续所有基线的**物理证据**，也是 M3 四条断言的**真实基线**（取代 09-17 旧数字）。

### 5.5 前置

M0.5 需要一条**真实可跑的链路**（Anaphase → Tuck → 上游）。若链路当前起不来，
**先修链路**，并把"起不来"本身记为**第一个物理事实**（它同样是选项 1/2/3 的判别依据）。
