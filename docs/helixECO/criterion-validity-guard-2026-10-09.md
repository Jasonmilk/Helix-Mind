# 判据有效性的守卫：双向可证伪（以及对人类一处判断的更正）

> 2026-10-09 ｜ 人类裁决：*"一个判据在'内容没变'和'内容变了'两个世界里都能红 ⇒ 按 Ω 是装饰品，按 G5 是伪证"*

## 一、先更正人类的 ② 一处事实（对事不对人）

人类断言：**ADR-0049 的 asset_parity 判据是 mtime ⇒ 只 touch 也会红 ⇒ V=0。**
**实测：不成立。**

```
判据里的 mtime      → 只出现在注释（解释为何**不用**它）；代码里没有
只 touch（md5 不变） → exit=0  **不红** ✅
mtime 做旧（2026-01） → exit=0  **仍不红** ✅
```

⇒ 该判据两轮前已由 mtime 改为**内容在场**（`contentPresent(artifact, assetBytes)`）。
**人类读到的是旧版。**（本会话我自己也犯过同类错：把历史行当当下设计、把 read 到的旧值当现行值。）

## 二、★ 但人类的方法论**站得住**，而且指到了一个**真缺口**

> **我只有正例夹具，没有反例夹具。**

**我的 `inject.sh` 追加字节 —— 同时改变了内容与 mtime。**
⇒ **若有人把判据改回读时钟，`--probe-all` 照样 RED ⇒ 闸门发现不了自己的退化。**
**⇒ "判据本身是否有效"没有守卫。** 这正是人类说的那条。

## 三、已补（`Cellrix`：`fixtures/<id>/counter.sh` + `probe_one` 反例阶段）

```
counter.sh   只 touch（字节不变），与 inject.sh 同契约（$F / 不污染）
probe_one    正例必须 RED → 反例必须 NOT RED
             触发   ⇒ [假阳性] + exit 2 + 账本 block{false-positive}
             无 counter.sh ⇒ 【具名】记 "negative direction unproven"，**不静默算通过**
```

**实测①**：`probe-all` → 心跳 RED ✅ + **"反例守住 — 内容未变时不红 ✅"** + 账本 pass + exit 0。

## 四、⚠️ 我没能证明的那半（明说）

我尝试反证"守卫能抓住读时钟的判据"，**做法本身有缺陷**：
我注入的 mtime 检查读 `assets[0]`（= `base.html`），而夹具注入的是 `glob_first` 选中的**另一个**文件
⇒ mtime 检查**盯错对象**恒为 ok、内容检查被 `||` 短路 ⇒ **正例阶段就先失败**。
**⇒ 那次 `exit 2` 不是守卫触发的，不构成证据。**
**⇒ "守卫能抓住判据退化"仍未证明**（待做：注入必须针对与夹具相同的 `$F`）。

**⇒ 这一条按人类自己的纪律记账：未跑通的部分不入证据。**
